# 🎨 カラーメモリー

スマホ依存にならない、短時間で楽しめる暇つぶしゲーム

## 🎮 ゲームについて

カラーメモリーは、色の順番を覚えて繰り返すシンプルなメモリーゲームです。スマホ依存を防ぐため、以下の工夫をしています：

- ✅ **明確な終了ポイント**: 10ラウンドでゲームが終わる
- ⏱️ **短時間プレイ**: 1プレイ約2〜5分
- 🎯 **達成感**: クリアすると満足感が得られる
- 📊 **記録の管理**: 最高記録を保存して自己ベストに挑戦

## 🕹️ 遊び方

### 1人プレイモード

1. **1人プレイ**を選択
2. 光る色の順番を覚える
3. 同じ順番で色のボタンをタップ
4. ラウンドが進むごとに1色ずつ増える
5. 10ラウンドクリアを目指そう！

### みんなでプレイモード（2〜4人）

1. **みんなでプレイ**を選択
2. プレイヤー数を選択（2〜4人）
3. 各プレイヤーの名前を入力
4. 交代でプレイして、誰が一番高いスコアを取れるか競う！
5. リアルタイムでスコアボードに順位が表示される
6. 全員終了後、優勝者が発表される

## ✨ 特徴

- 🎵 各色に異なる音がついている
- 👥 **マルチプレイヤー対応**（2〜4人で交代プレイ）
- 🏆 **リアルタイムスコアボード**
- 📱 スマホ・タブレット対応
- 💾 最高記録を自動保存
- 🎨 綺麗なグラデーションデザイン
- 🌐 オフラインでも動作

## 🎯 ゲームのルール

- **ラウンド1**: 1色を覚える
- **ラウンド2**: 2色を覚える
- **ラウンド3**: 3色を覚える
- ... 以下、10ラウンドまで続く

### スコア計算

- 各ラウンドクリアで `ラウンド数 × 10` ポイント
- 例: ラウンド5をクリアすると50ポイント獲得

## 🛡️ スマホ依存防止の工夫

1. **時間制限**: 最大10ラウンドで自動終了
2. **一区切り**: 各プレイに明確な終わりがある
3. **シンプル**: 複雑な課金要素や継続プレイの誘導なし
4. **健全**: 短時間で満足感が得られる設計
5. **社交的**: マルチプレイヤーで対面コミュニケーションを促進
6. **交代制**: 画面を見続けることなく、自然な休憩が入る
