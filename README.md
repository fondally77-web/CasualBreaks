# 🎨 カラーメモリー

スマホ依存にならない、短時間で楽しめる暇つぶしゲーム

## 🎮 ゲームについて

カラーメモリーは、色の順番を覚えて繰り返すシンプルなメモリーゲームです。3つの難易度から選べるので、初心者から上級者まで楽しめます。スマホ依存を防ぐため、以下の工夫をしています：

- ✅ **明確な終了ポイント**: 難易度に応じて10〜20ラウンドで終了
- ⏱️ **短時間プレイ**: 1プレイ約2〜10分
- 🎯 **達成感**: クリアすると満足感が得られる
- 📊 **記録の管理**: 最高記録を保存して自己ベストに挑戦
- 🎚️ **3段階の難易度**: スキルに合わせて選べる

## 🕹️ 遊び方

### 1人プレイモード

1. **1人プレイ**を選択
2. **難易度を選択**（イージー・ノーマル・ハード）
3. 光る色の順番を覚える
4. 同じ順番で色のボタンをタップ
5. ラウンドが進むごとに1色ずつ増える
6. 難易度に応じたラウンド数のクリアを目指そう！

### みんなでプレイモード（2〜4人）

1. **みんなでプレイ**を選択
2. **難易度を選択**（イージー・ノーマル・ハード）
3. プレイヤー数を選択（2〜4人）
4. 各プレイヤーの名前を入力
5. 交代でプレイして、誰が一番高いスコアを取れるか競う！
6. リアルタイムでスコアボードに順位が表示される
7. 全員終了後、優勝者が発表される

### 難易度について

| 難易度 | ラウンド数 | 色数 | スピード | おすすめ |
|--------|------------|------|----------|----------|
| 😊 イージー | 10 | 4色 | ゆっくり | 初心者・リラックスプレイ |
| 🙂 ノーマル | 15 | 4色 | 普通 | 通常プレイ・適度な挑戦 |
| 😤 ハード | 20 | 6色 | 速い | 上級者・本気モード |

## ✨ 特徴

- 🎚️ **3段階の難易度選択**（イージー・ノーマル・ハード）
- 🎵 各色に異なる音がついている（ハードモードは6色）
- 👥 **マルチプレイヤー対応**（2〜4人で交代プレイ）
- 🏆 **リアルタイムスコアボード**

- 🎨 綺麗なグラデーションデザイン
- 🌐 オフラインでも動作

## 🎯 ゲームのルール

- **ラウンド1**: 1色を覚える
- **ラウンド2**: 2色を覚える
- **ラウンド3**: 3色を覚える
- ... 以下、難易度に応じたラウンド数まで続く
  - イージー: 10ラウンド
  - ノーマル: 15ラウンド
  - ハード: 20ラウンド

### スコア計算

- 各ラウンドクリアで `ラウンド数 × 10` ポイント
- 例: ラウンド5をクリアすると50ポイント獲得
- ハードモードは長く続くため、より高得点を狙える！

## 🛡️ スマホ依存防止の工夫

1. **時間制限**: 難易度に応じて10〜20ラウンドで自動終了
2. **一区切り**: 各プレイに明確な終わりがある
3. **シンプル**: 複雑な課金要素や継続プレイの誘導なし
4. **健全**: 短時間で満足感が得られる設計
5. **社交的**: マルチプレイヤーで対面コミュニケーションを促進
6. **交代制**: 画面を見続けることなく、自然な休憩が入る
7. **適度な難易度**: 簡単すぎず難しすぎず、自分に合った難易度を選べる
